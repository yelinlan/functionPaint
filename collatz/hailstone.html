冰雹猜想 · Collatz 3n+1 研究指南

「像冰雹一样忽上忽下的数列，真的都落到 1 吗？」—— 6 种研究思路 + 交互式实验 + 行动路线

0 · 冰雹猜想是什么

对任意正整数 n，反复施加规则：

T(n) = n/2  (n 为偶数)   |    T(n) = 3n + 1  (n 为奇数)

猜想（Collatz, 1937；亦称 3n+1、Syracuse 问题、Hasse 算法）：无论从哪个正整数出发，最终都会到达 1（随后进入 1 → 4 → 2 → 1 的循环）。

因轨迹反复冲高又暴跌、犹如冰雹起落，故在中文里被称为「冰雹猜想」（hailstone sequence）。Ulam 曾把它形象地说成「数学中的一只猛兽」，Erdős 评价：「数学也许还没有准备好解决这样的问题。」

已验证范围
所有 n ≤ 268（≈2.95×1020，Elia Komlath, 2024）均成立。
已知的危险
只证明了：若存在发散轨道/非平凡循环，其起始值必须极其巨大（模约束极强）。
悬赏
该问题的经典悬赏 500 美元（Erdős 遗留至今），至今无人认领。

快速体验：输入任意 n，看它的冰雹轨迹

试试 27、704511、63728127 ……

为什么它重要（研究价值）

  • 极致简单 vs 极致困难：小学生都能复述规则，但用尽现有解析工具也无从下手——是检验新方法的「试金石」。
  • 与正规数、素数分布、动力系统、计算复杂性（P vs NP 相关的不可判定性思想）有深刻联系。
  • 入门门槛低、验证成本低：一台电脑即可做前沿级的数值实验，适合初学者积累研究手感。

思路一 · 数值实验与轨迹模拟（最直接的入手点）

核心思想：先「玩」数字。计算停止时间（stopping time，到目前为止的最大值）、总步数（total stopping time，到 1 的步数）、轨迹形状，寻找反常样本与规律。

第 0 步
纵轴为当前值（对数刻度），绿色点=偶数步（÷2），橙色点=奇数步（×3+1）。

批量扫描：n = 1 … N 的总停止时间散点

尚未扫描。散点越往上代表该数「飞得越高、走得越久」。

思路二 · 逆向轨道：从 1 倒推的树

正向难证，就反着看。给定 m，可能的前驱只有两种：

m → 2m （m 由偶数除 2 得到）  |   m → (m−1)/3 （当 m ≡ 4 (mod 6) 时，由奇数 3n+1 得到）

从 1 出发反复前驱，得到一棵「Collatz 树」。于是猜想等价于：这棵树是否覆盖所有正整数？（每个整数要么在树上，要么落在一个非平凡循环/发散分支中。）

实线 = ×2 分支（一定存在）；虚线 = (m−1)/3 分支（需要 m≡4 mod 6 且结果为正整数）。深挖任意一支都会迅速指数膨胀——这就是困难所在。

该思路下的可研究问题

  • 循环刻画：任何循环都对应树上的「自我碰撞」。已证：任何非平凡循环中必有元素 < 2k（k 为奇数个数），且最大元必然是奇数。
  • 反向覆盖密度：统计深度 d 内的节点数 ~ 2d，但 (m−1)/3 分支期望只占约 1/6。能否证明「漏网之鱼」数量为 0？
  • 碰撞结构：正向不同轨道的第一次碰撞点分布——若碰撞总发生在 1，则猜想成立。
  • 具体技术：用模 2k 或 p-进赋值约束循环；借助格基约减 (LLL) 搜索循环候选。

思路三 · 二进制与奇偶模式（Syracuse 问题 / 局部化方法）

3n+1 在二进制下有天然结构：偶数右移一位；奇数 n 的 3n+1 至少是偶数（实际上末位必为 0），立刻至少右移一位。

观察每步的二进制变化与奇偶串

奇偶串 (Parity String) 与加速

把一段连续的运算按「奇/偶」压缩成 0/1 串，可用 Syracuse 函数 一次跳过所有偶数步：

S(y) = (3y + 1) / 2v₂(3y+1)   （y 为奇数，v₂ 为 2 的幂次）

由此产生几类成熟技术，适合作为论文/综述切入点：

  • 奇偶向量 (parity vector)：轨道由其奇偶序列唯一决定（determinacy of parity sequences，Shastri 等）。两个轨道若共享充分长的奇偶段就可判同。
  • 局部化 (Terras, 1976; Krasikov–Lagarias, 2003)：证明「几乎所有 n」的轨迹最终下降，依赖 ∑ log 项的 2-adic 控制。
  • 统计/局部-整体方法：考虑 mod 2k 的一致分布，用 Kummer 型同余、p-进 L 函数控制 3s mod 2t 的分布。
  • 算术加速：用 (3a·n + b)/2c 的模板批量跳跃，可将模拟速度提升 10~100 倍。
可做的小课题：枚举长度 ≤ 20 的奇偶串，统计其出现频率与可达起点集合；用奇偶串重写搜索循环的方程。

思路四 · 概率 / 随机启发式模型

忽略具体数值、只看「奇偶性随机」的假设：

期望对数变化 ≈ ½·log₂(1/2) + ½·log₂(3/2)... 精确到每个奇数步后必跟 ≥1 次除 2：
E[Δ log n] ≈ ½·(log₂ ½) + ½·(log₂ 3/4) = −0.2075 < 0

即：平均而言每步把 n 乘以约 3/4，所以轨迹「期望上」指数下降到 1——这解释了为什么几乎所有轨道都下落，但期望下降 ≠ 必然下降，这正是证明的鸿沟（相关性、尾部事件、无界波动都可能破坏期望论证）。

蓝线 = 随机奇偶模型的 log₂ 轨迹（大多向下漂移，但个别向上冲）；橙线 = 真实 3n+1 轨迹。

启发式能说什么、不能说什么

能解释不能保证
为什么 n 很大时「几乎总是」回到小数值（Erdős 型论证、Terras 定理的直觉来源） 不存在极少数「永远上升」的怪异起点
峰值/步数的统计分布（log-normal 型、停止时间近似 ∝ (log n)²） 不存在非平凡循环（随机模型里也可能有循环）
变体方程中哪些 kx+1 会发散（期望 Δlog 的符号） 从「以概率 1」升级到「对所有 n」的确定性结论
研究提醒：把随机论证写成严格证明是常见失败点。可研究的方向：给奇偶序列建立鞅/马尔可夫链模型，并控制偏差（concentration inequality），争取把「几乎处处」推进到更大范围。

思路五 · 图形统计与反例搜索（计算实验方向）

峰值倍数分布 (max/起点)

反例搜索工程实践（可直接写代码开跑）

  1. 位宽与溢出：用 128/256 位整数或大数库；峰值可达起点的 ~10³·log 倍，必须预留余量。
  2. 查表 + 约定：预计算 n < 10⁷ 的停止时间表，轨迹降到表内直接查表返回（jump table），速度提升 1~2 个数量级。
  3. 并行分片：按 n mod P 分片，多核/多机各扫一段；可参考 ycruncher、Wikipedia 的分布式项目做法。
  4. 断言式验证：对每条轨迹记录 max 与 268 内已验证结果比对；任何「超过 k 步未落回」的候选立即上报。
  5. 可视化反馈：把停止时间热力图、峰值随 n 的锯齿结构画出来，异常会「跳出来」。
  6. 可发表的增量：更宽范围的验证 + 你独有的分布统计/新不变量（如 mod 3、mod 4 分类下的步数差异）。
数据源：OEIS A006577（停止时间）、A006885（最大值）、A070165（奇数步数）、Lagarias 编的《The Ultimate Challenge》附录数据。

思路六 · 变体与推广（最容易出成果的方向）

3n+1 是一个庞大族系的特例：kx±1 类问题。改变 k 后会出现三类世界：收敛到平凡循环、发散（存在无穷轨道）、悬而未决。相图（phase diagram）研究是很适合新手的切入点。

柱状：每个 k 下，起点 1..N 的「平均 log₂(最大值)」——越低表示越收敛，越高/越不稳定暗示发散或长循环。

可选的推广课题

  • kx+1 相图：偶数 k + 1 恒为奇数 → 增长最快；k ≡ 2 mod 4 时常出现发散；可给出数值相图 + 循环枚举表。
  • 高维/矩阵版本：3×3 整数矩阵的 «Collatz» 乘法（Conway 的问题是不可判定的！）——可作综述/科普。
  • 函数环上：多项式 Collatz（如 (x²+x+1) 系数 mod 2）。
  • 与其它猜想的桥：Collatz 猜想 ⇒ 关于正规数/素数分布的命题（Rempe 等 2020：Collatz 蕴含无限多 Collatz 猜想型素数）。
  • 算法/工程向：GPU 上的批量验证、压缩存储轨迹（parity + run-length）、用 SAT/SMT 搜小循环。
为什么这个方向推荐新手：3n+1 本身久攻不克，但变体族系很多结论「半开放」，数值 + 猜想式结论的论文空间较大，且极易做可视化。

给你的研究行动路线

  1. 第 1 周 · 建立直觉：手算 n=6、27、9 的轨迹；读 Collatz 猜想的科普综述（Wikipedia 中/英 + Lagarias 的 survey 第 1 章）。
  2. 第 2 周 · 写代码：轨迹生成器 + 停止时间表 + 本页所有交互的源码（就是本 HTML 的 JS）。能复述随机模型为什么给出 −0.2075。
  3. 第 3–4 周 · 选一条思路深挖：二选一——(A) 数值统计：做一张别人没画过的分布图并解释它；(B) 逆向树/循环：穷举深度 d 的所有循环候选，给出新的模约束。
  4. 第 5–6 周 · 读原始文献：Terras(1976)、Krasikov–Lagarias(2003)、Tao(2019, "Almost all orbits attain almost bounded values")——目标是能看懂证明骨架。
  5. 第 7–8 周 · 输出：写一篇中文综述/实验报告，或选一个变体（kx±1 相图、奇偶串统计）写成可投稿的小论文/课程报告。
  6. 持续 · 记录异常：任何你发现的「疑似长于预期」「疑似更高峰值」样本都是好素材。

def hail(n):
    steps, mx, parity = 0, n, ""
    while n != 1:
        if n % 2 == 0: n //= 2; parity += "0"
        else:          n = 3*n + 1; parity += "1"
        mx = max(mx, n); steps += 1
    return steps, mx, parity
